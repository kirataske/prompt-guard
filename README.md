# PromptGuard  

Система виявлення атак типу prompt injection для застосунків на базі великих мовних моделей (LLM). Забезпечує багаторівневий захист вхідних запитів перед їх передачею до основної моделі.

## Архітектура

Проєкт реалізує три рівні інспекції тексту:

1. **Евристичний аналіз:** Швидка перевірка за допомогою регулярних виразів для відсікання базових атак.
2. **ML-модель (Рівень 2):** Модель на базі текстових ембедингів `sentence-transformers` та логістичної регресії для визначення типу та рівня загрози.
3. **LLM-as-a-judge :** аналіз  за допомогою зовнішньої LLM.

## Старт

1. Створіть та активуйте [віртуальне середовище](https://fastapi.tiangolo.com/virtual-environments/), а потім встановіть залежності:

```
# Створення віртуального середовища
python -m venv .venv
# Встановлення пакетів
pip install -r requirements.txt
```

Створіть файл `.env` у корені проєкту та додайте необхідні параметри згідно з інструкцією в розділі [Налаштування API](#налаштування-api-llm-as-a-judge).

Перед запуском сервера необхідно завантажити датасет та навчити модель:

```
# 1. Завантаження датасету 
python build_dataset.py

# 2. Навчання ML-моделі
python train_model.py
```

Для запуску сервера скористайтеся командою:

```
uvicorn app.main:app
http://127.0.0.1:8000
http://127.0.0.1:8000/docs
```

## Налаштування API (LLM-as-a-judge)  

Як LLM-as-a-judge (Рівень 3) було обрано модель **`llama-3.3-70b-versatile`**, яка працює на базі  **GROQ**.

**Інструкція з підключення:**
1. Зареєструйтесь на [Groq Cloud](https://console.groq.com/) та отримайте безкоштовний API-ключ.
2. Створіть файл `.env` у кореневій теці вашого проєкту.
3. Додайте ваш ключ до файлу у наступному форматі:

```
GROQ_API_KEY=API-ключ
```

P.S. Перевірити залишок токенів та підвищити тариф за необхідності можна за [посиланням](https://console.groq.com/dashboard/metrics).

## API детектора

### Аналіз контенту

* **Шлях:** `/analyze`
* **Метод:** `POST`
* **Формат:** `JSON`

**Тіло запиту:**

```
{
    "text": "текст для перевірки на ін'єкцію"
}
```

**Відповіді:**

**При успішному виконанні аналізу:**
* **HTTP код:** `200`
* **Вигляд тіла:**

```
{
    "verdict": "clean | suspicious | blocked",
    "severity": "low | medium | high",
    "attackType": "none | direct_injection | indirect_injection | system_prompt_leak | role_play | obfuscation | payload_splitting",
    "segment": "string"
}
```

**Помилка серверу (наприклад, збій API LLM):**
* **HTTP код:** `500`
* **Вигляд тіла:**

```
{
    "detail": "текст внутрішньої помилки"
}
```
