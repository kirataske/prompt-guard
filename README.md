# PromptGuard

Проєкт системи виявлення та попередження виконання інʼєкцій у запитах до користувача.

Є проміжним рівнем між користувачем та кінцевою великою мовною моделлю.

# Принцип роботи (або ж алгоритм):

1. Фронтенд приймає та надсилає користувацький запит до проксі.
2. Проксі валідує користувацький запит та направляє його на аналіз до детектора.
3. Детектор починає аналіз запиту за трьома рівнями:
   - Рівень 1: евристичний аналіз за RegExpами.
   - Рівень 2: власна навчена модель для аналізу запиту.
   - Рівень 3: LLM-as-a-Judge (використовується стороння модель для аналізу запиту)
4. Проксі отримує результати аналізу запиту від детектора:
   - При задовільному висновку запит передається на кінцеву велику мовну модель, після чого відповідь моделі повертається до фронтенду.
   - При виявленні інʼєкції виконання запиту блокується, натомість на фронтенд передається запис про інцидент.
5. Фронтенд відображає згенерований результат, або ж запис інциденту, якщо такий було отримано від проксі.

# Розгортання системи:

Першим кроком варто отримати ключі API для [Groq](https://console.groq.com/docs/quickstart) та [Gemini](https://ai.google.dev/gemini-api/docs/get-started).

Далі виконайте налаштування компонентів у такому порядку: детектор, проксі й наприкінці - фронтенд.

**ВАЖЛИВО**: Навчати модель детектора **НЕ ТРЕБА**, одразу переходьте до налаштування середовища й запуску. Чому? Тому що модель вже існує за цим шляхом: `detector/models`.
